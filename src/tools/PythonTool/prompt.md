# python_tool

## DESCRIPTION
执行 Python 脚本文件或一段 Python inline 代码，并返回退出码、标准输出和标准错误。
## PROMPT

### WHEN_TO_USE

以下情况可以使用本工具：

- 执行用户指定的现有 `.py` 脚本。
- 使用简短 Python 代码进行计算、数据处理或格式转换。
- 验证 Python 语法、导入、函数行为或项目运行结果。
- 专用工具无法完成时，进行项目相关的非交互式诊断。
- 用户要求执行测试、构建、格式化或其他项目开发命令时。

读取普通文件优先使用 read_file，搜索项目内容优先使用 grep。
不要为了简单读取或搜索而使用 Python。

### INPUT_RULES

必须且只能提供一种执行来源：

- `script_path`：执行已有 `.py` 文件，必须是绝对路径。
- `code`：执行临时 Python 代码。

不能同时提供 `script_path` 和 `code`，也不能两个都不提供。

通用参数：

- `cwd`：执行工作目录的绝对路径。
- `args`：参数列表，每个参数必须是独立字符串。
- `python_path`：指定 Python 解释器；不填时使用当前解释器。
- `timeout`：超时时间，范围为 1 到 120 秒。

使用 `code` 验证信息时：

- 必须实际调用需要验证的函数或操作。
- 必须使用 `print(...)` 输出检查结果。
- 不要只写 import、变量赋值、函数定义或不会执行的表达式。

### EXAMPLES

执行脚本：

{"script_path":"E:\\project\\scripts\\check.py","args":[]}

执行临时代码：

{"code":"from pathlib import Path\nprint(Path.cwd())","cwd":"E:\\project"}

### PERMISSIONS

默认允许：

- 导入标准库和当前 Python 环境中已安装的依赖。
- 读取工作目录中的项目文件。
- 执行计算、解析、测试和只读诊断。
- 当没有专用工具时，使用
  `subprocess.run([...], shell=False)` 执行项目相关的非交互命令。
- 用户明确要求修改项目时，在工作目录内创建或修改相关文件。

只有用户明确要求时才允许：

- 安装或升级依赖。
- 访问网络服务。
- 修改工作目录之外的文件。
- 删除、移动或批量覆盖文件。
- 修改环境变量或项目配置。
- 启动持续运行的进程。

始终禁止：

- 使用交互式命令。
- 启动无限循环或无人管理的后台进程。
- 访问或输出无关的密钥、凭据和隐私数据。
- 执行范围不明确的批量删除或系统级修改。

### OUTPUT_RULES

- 检查或验证任务必须输出可供判断的结果。
- 优先输出简短文本或 JSON。
- 执行失败时根据 stderr 和退出码纠正一次。
- 不要在参数和代码没有变化时重复调用。
- 退出码为 0 但没有输出时，先检查是否忘记实际调用函数或 print。
