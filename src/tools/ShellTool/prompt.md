# shell_tool

## DESCRIPTION
在 agent 工作目录中执行一次非交互式 Shell 命令，并返回退出码、标准输出和标准错误。

## PROMPT

### WHEN_TO_USE

- 执行测试、构建、格式化、版本控制和项目脚本。
- 调用 Python、Node.js、Git、包管理器以及其他命令行程序。
- 需要使用管道、重定向或条件执行等 Shell 语法。

读取文件优先使用 read_file，搜索内容优先使用 grep。不要用 shell_tool 代替已有的专用工具。

### INPUT_RULES

- `command`：要执行的完整命令。Windows 使用 PowerShell，其他平台使用 Bash/Sh。
- `cwd`：可选工作目录；相对路径基于 agent 工作目录解析，不填时使用 agent 工作目录。
- `timeout`：超时时间（秒），默认 30，最大 600。

每次调用都在新的非交互式 Shell 中执行。变量、函数和 `cd` 状态不会在调用之间保留；需要指定目录时优先使用 `cwd`。

### PERMISSIONS

本工具可能读取、创建、修改或删除文件，也可能启动其他程序。严格服从用户授权范围：

- 只读任务只能执行只读命令。
- 只有用户要求修改时才能运行会修改项目的命令。
- 安装依赖、访问网络、修改项目外文件、删除或批量覆盖内容必须有明确授权。
- 不得输出无关的密钥、凭据或隐私数据。

### LIMITS

- 不支持交互式输入和全屏终端程序。
- 超时或取消会终止命令及其可观察到的子进程。
- 输出按字节限制；过长时只返回尾部，并在可用时给出完整输出文件路径。
- 非零退出码是命令结果，不代表工具协议失败。检查 stderr 和退出码后再决定下一步。
- 超时命令可能已经产生部分副作用；重试前先检查最终状态，不要自动重跑非幂等命令。
