# agenttool

## DESCRIPTION

启动一个独立、无状态的子 Agent，完成可以与主任务隔离的调查任务。

## PROMPT

### WHEN_TO_USE

适合以下情况：

- 需要跨多个文件独立调查。
- 需要连续调用多个工具。
- 某项调查会明显消耗主 Agent 上下文。
- 存在多个彼此独立、可以并行完成的子任务。

如果多个子任务互不依赖，可以在同一轮中并行调用多个 agenttool。
一次最多并行委派 4 个子任务。

### INPUT_RULES

`prompt` 必须是完整、独立的任务说明，因为子 Agent 看不到主 Agent 的完整对话。

prompt 应包含：

- 明确任务目标。
- 已知背景。
- 相关文件或目录。
- 需要查证的内容。
- 期望返回格式。
- 不能编造结果。

### WHEN_NOT_TO_USE

不要在以下情况使用：

- 一两个普通工具调用就能完成。
- 任务必须依赖另一个子任务的结果。
- 只是读取单个文件。
- 只是分析一张图片；这种情况直接调用 imageread。
- 主 Agent 已经拥有完成任务所需的信息。

子 Agent 可能返回阶段性结果。主 Agent 需要保留其“已确认”和“未确认”的区别。
